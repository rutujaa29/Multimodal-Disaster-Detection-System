# 🌍 Multimodal Disaster Detection System

An AI-powered disaster detection system using:

- EfficientNet-B0
- ResNet50
- BERT
- Streamlit
- PyTorch

## Features

- Fake vs Real Image Detection
- Disaster Classification
- Multimodal AI (Image + Text)
- Streamlit Dashboard

## Disaster Classes

- Flood
- Fire
- Earthquake
- Hurricane

## Installation

```bash
pip install -r requirements.txt
```
